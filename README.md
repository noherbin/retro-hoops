# Retro Hoops

A retro pixel-art basketball game with a franchise mode and online multiplayer.

**Play:** https://noherbin.github.io/retro-hoops/

The game is `index.html`; the announcer's recorded voice is in `rh-voice.mp3` / `rh-voice.json`.

Announcer voices were generated with [Kokoro-82M](https://github.com/hexgrad/kokoro) (Apache 2.0).
